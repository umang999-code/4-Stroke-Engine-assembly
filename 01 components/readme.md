## piston 
### CAD Model
https://github.com/umang999-code/4-Stroke-Engine-assembly/blob/main/01%20components/piston.SLDPRT

Function -
The piston moves reciprocally inside the cylinder and 
transfers the force produced during combustion to the connecting rod.

Description -
The piston is one of the main moving components of the engine. 
It moves up and down during the four strokes of the engine cycle.


## Crankshaft
### CAD Model
https://github.com/umang999-code/4-Stroke-Engine-assembly/blob/main/01%20components/Crank%20shaft.SLDPRT

Function -
The crankshaft converts the reciprocating motion 
of the piston into rotary motion.

Description -
The crankshaft is connected to the connecting rod and rotates as the piston moves. 
It transmits mechanical power to the output side of the engine.



## Lower Block
### CAD Model
https://github.com/umang999-code/4-Stroke-Engine-assembly/blob/main/01%20components/lower%20block.SLDPRT

Function -
The lower block forms the lower supporting structure of the engine 
and provides support for the crankshaft assembly.

Description -
The lower block acts as a structural housing for the lower portion of the engine 
and helps maintain the proper position of the rotating components.


## Upper Block
### CAD Model
[Download/View upper block CAD File](./Components/upperblock.SLDPRT)

Function -
The upper block forms the upper structure of the engine and
provides the main housing around the cylinder and piston assembly.

Description -
The upper block is joined with the lower block to form the main engine body
and provides structural support to the engine components.


## Connecting Rod
### CAD Model
[Download/View connecting rod CAD File](./Components/connectingrod.SLDPRT)

Function -
The connecting rod connects the piston to the crankshaft
and transfers force and motion between them.

Description -
The connecting rod converts the reciprocating movement of the piston into the rotational
movement of the crankshaft through its connection with the crank mechanism.


## Crankshaft Support Shaft
### CAD Model
[Download/View shaft CAD File](./Components/shaft.SLDPRT)

Function -
The shaft provides support and allows the crankshaft 
assembly to rotate properly.

Description -
The shaft is positioned through the crankshaft assembly
and provides a rotational support point for the crankshaft.
