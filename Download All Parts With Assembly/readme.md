## Download Complete 4-Stroke IC Engine CAD Files:

The complete 4-Stroke Internal Combustion (IC) Engine CAD model is provided in SolidWorks format for engineering study, design reference, assembly practice, and further modification.

## Included Files :

The project contains all the individual components and the complete engine assembly.
🔩 Individual Part Files (.SLDPRT)
The component folder includes major engine parts such as:
Engine Lower Block
Upper Engine Head
Crankshaft
Piston
Piston pin
Connecting Rod
Shaft and other supporting components

## Assembly File (.SLDASM)

The complete assembly includes:
Piston and connecting rod assembly
Crankshaft assembly
Engine block and cylinder head
Properly positioned engine components
SolidWorks mates between components
Complete 4-Stroke IC Engine configuration


## Software Required:
SOLIDWORKS (recommended)
The .SLDASM assembly should be opened with all referenced .SLDPRT files available.


## How to Download and Open:
Download the complete project repository from GitHub.
Download all .SLDPRT component files along with the .SLDASM assembly.
Keep all component files in their respective project folders.
Do not rename or move the component files after downloading.
Open the main 4-Stroke IC Engine .SLDASM file in SOLIDWORKS.
If SOLIDWORKS asks for a missing component, browse to the folder containing the original .SLDPRT file.
After all references are resolved, the complete engine assembly will open correctly.


## Important: 
The assembly file contains references to its individual part files. 
Therefore, all .SLDPRT files must be downloaded along with the .SLDASM file. Avoid changing the original file names or folder structure
